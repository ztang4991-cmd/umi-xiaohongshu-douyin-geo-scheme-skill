# UMI 小红书 / 抖音 / GEO 方案制作 Skill

这是聚尤米 UMI 的小红书、抖音与 GEO 方案制作工作区整理版。

## 内容范围

- `*.py`：方案生成、数据处理和排版辅助脚本
- `*.js`：文档生成、采集和浏览器辅助脚本
- `GEO产品_多平台发布机制详解.md`：GEO 多平台发布方法论
- `小红书抖音AI协作工作流.md`：小红书与抖音 AI 协作流程
- `客户异议处理_*.md`：销售沟通与异议处理话术素材
- `Instructions/`、`Labfiles/`：原项目已有的学习资料和示例代码

## 上传边界

本整理版不上传已制作的客户方案、诊断报告、提案、行动清单、演示文稿和 PDF/DOCX/HTML 成品。原工作区中的 `deliverables/`、`output/`、`tmp/` 以及质检截图目录保持不变，但由 Git 忽略。

客户抓取导出、联系人截图、来源摘录和本机权限配置也不进入 Git 提交，避免泄露客户数据或本地环境信息。

完整边界记录见 `UPLOAD_INVENTORY.md`。

## 仓库名称

GitHub 仓库名使用 `umi-xiaohongshu-douyin-geo-scheme-skill`。用户给出的中文展示名为“umi小红书/抖音/GEO方案制作skill”；GitHub 仓库名不能包含 `/`，因此使用连字符规范化。

## 使用前检查

1. 复制 `.env.example` 为本地 `.env`，填写自己的环境变量。
2. 不要提交真实密钥、客户联系人、抓取原始数据或客户交付成品。
3. 运行脚本前，按脚本顶部说明安装对应的 Python 或 Node.js 依赖。
