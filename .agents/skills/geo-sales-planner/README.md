# geo-sales-planner

面向宴会场地、线上运营和 ToB 销售方案的 Codex Skill。它把团队的销售方案工作协议和一套可复用的思考方法封装为可共享目录。

## 能力

- 方案前置的单题式引导问答，最多 6 个主问题；
- 需求确认单：事实、假设、关键变量、主问题、交付物和验收标准；
- 双层解释、反向拆解、横纵分析、事实核查；
- 专家会诊、第一性原理、跨领域借解、双向钢人论证和最小实验；
- 宴会场地线上获客、线下承接、成交转化、GEO、小红书和抖音方案交付；
- 团队案例素材的使用边界和隐私/授权检查。

## 安装/共享

将整个 geo-sales-planner 目录复制到团队约定的 .agents/skills/ 或 Codex Skill 目录中，保留 SKILL.md、agents/openai.yaml 和 references/。技能不依赖个人绝对路径；项目案例素材有则读取，没有则标记待补素材。

可直接使用：使用 $geo-sales-planner，为这个客户制定合作方案。先通过单题式问答帮我澄清需求，不要直接开始写方案。

出于隐私与授权控制，微信群截图等案例图片不随技能源码分发，由团队通过已批准的素材库单独共享。

## 项目协同

如果项目根目录有 AGENTS.md，以项目 AGENTS.md 的最新规则为准。本技能提供可复用流程，不能替代客户授权、账号权限、真实数据、平台规则核验或法律审核。
