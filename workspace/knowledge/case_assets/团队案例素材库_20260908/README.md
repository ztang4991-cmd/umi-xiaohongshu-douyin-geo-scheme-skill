## 使用规则

1. 按方案主题选案例：婚宴选春生婚宴号、祥和、牧云台；团建选介个院子、春生婚宴号；餐饮/下午茶选春生漂亮饭号、悦哉；账号矩阵选春生三账号。不机械堆放全部截图。
2. 只描述截图直接支持的事实（账号名、定位、简介、可见数字及截图日期）。不得据此编造合作时间、服务范围、成交数据、增长业绩或效果承诺。
3. 粉丝数、获赞与收藏数是截图时点的快照，引用时写明“公开快照·日期”，不当作运营成果。
4. 微信群截图默认只作内部佐证；对外使用前必须脱敏并确认授权。
5. 不得裁剪、放大或重新组合截图来制造原图未表达的结论；对外发布前检查隐私、授权和敏感信息。
